## Setup Instructions

1. Extract the ZIP file.
2. Open the project folder in terminal / VS Code.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Run the development server:
   ```bash
   npm run dev
   ```
5. Open the local link in browser (e.g. `http://localhost:5173`).
